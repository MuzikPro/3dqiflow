## 🔴 红线 1：中气 ≠ 肺气

```
❌ 错误写法：
   "中气即肺气"
   "中气就是呼吸之气"
   "中气指肺"

✅ 正确写法：
   "中气 = 脾胃之气（土气）"
   "脾胃居中，为圆运动的轴心"
   "肺主气、肾藏精是右降路径上的两个关键节点"
   "中气如轴，四维如轮"

📖 出处：彭子益《圆运动的古中医学》原理上篇
```

## 🔴 红线 2：方剂必须用经方原名

```
❌ 错误写法：
   "泻火汤"
   "清火方"
   "补肝汤"

✅ 正确写法：
   "大黄黄芩黄连泻心汤"（泻火的具体方名）
   "黄连阿胶汤"（心火不降）
   "当归生姜羊肉汤"（木气不升）
   "肾气丸"（肾水不升）
   "麦门冬汤"（金气不降）
   "理中丸"（运轴代表方）
   "小建中汤"（运轮代表方）
   "乌梅丸"（轴轮并运代表方）
   "四逆汤"（少阴病·回阳救逆）
   "真武汤"（少阴病·温肾化水）
```

## 🔴 红线 3：太乙神 ≠ 经典术语

```
❌ 错误写法：
   "太乙神出自《内经》"
   "太乙神是经典固定称谓"

✅ 正确写法：
   "太乙神（教学术语，指胃经与肾经的统称）"
   "太乙神非经典原文，是后人归纳的教学用语"
```

## 🔴 红线 4：节气对应 ≠ 绝对公式

```
❌ 错误写法：
   "立春必然对应肝木升发"
   "冬至必生肾病"
   "每个节气精确对应某经"

✅ 正确写法：
   "二十四节气是圆运动的时空坐标（模型简化）"
   "临床必须辨证，不可机械套用节气-经气对应"
   "彭子益：'学知二十四节气，须用功夫，一点不可含糊'"
```

## 🔴 红线 5：相火归属

```
❌ 错误写法：
   "相火只属于心包"
   "三焦不是相火"
   "相火 = 心火"

✅ 正确写法：
   "相火寄于水火之间"
   "心包（手厥阴）+ 三焦（手少阳）同属相火系统"
   "相火贯穿上下，为能量传导通道"
```

## 🔴 红线 6：六经统属

```
❌ 错误写法：
   "三阳统于太阳"
   "三阴统于少阴"

✅ 正确写法：
   "彭子益：三阳统于阳明，三阴统于太阴"
   "把六经辨证简化为脾胃中气升降问题"
   "阳明为三阳之里，太阴为三阴之枢"
```

---

## 🔴 红线 7：凡病皆本气自病

```
❌ 错误写法：
   "外邪直接打垮了你"
   "邪气是疾病的主因"
   "治病就是驱邪"

✅ 正确写法：
   "凡病皆本气自病"（彭子益原话）
   "外邪是诱因，根本是自身圆运动先乱"
   "治病的关键是恢复人体本气的圆运动"
   "治病的本质 = 帮圆运动重新转起来"
```
